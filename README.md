# Analysis_Ukraine — данные о потерях из UALosses

Данные с [ualosses.org](https://ualosses.org/uk/soldiers/): поимённая база задокументированных
потерь ВСУ из открытых источников (погибшие, пропавшие без вести, пленные).
На 24.11.2026 в базе **234 573 человека**. Сайт прямо разрешает распространять данные
(«Поширювати дозволено й дуже бажано!»). В видео стоит указать источник: UALosses.

## Что лежит в репозитории

| Путь | Что это |
|---|---|
| `data/ualosses_tables.xlsx` | Все таблицы одной книгой Excel, каждая на своём листе |
| `data/tables/*.csv` | Те же таблицы в CSV (UTF-8 с BOM, открываются в Excel и Google Sheets) |
| `data/raw/` | Исходные агрегаты сайта (`places.json.gz`, `facts.json.gz`) и страница статистики |
| `scripts/fetch_ualosses.py` | Скачивает свежие данные с сайта |
| `scripts/build_tables.py` | Строит из них таблицы |

Обновить данные:

```bash
python3 scripts/fetch_ualosses.py --rank-counts   # ~3 минуты
python3 scripts/build_tables.py
```

## Графики для видео

`charts/`: PNG 3840×2160 (16:9), каждый в светлой и тёмной версии.

- `weekly_losses_*.png`: потери по неделям с 24.02.2022, по статусам.
  Последние недели затенены, потому что данные по ним ещё поступают.
- `place_nizhyn_origin_*.png`: военные из Нежина. Общее число, разбивка по статусам
  и по годам, на 10 тыс. жителей, а также громада и район.
  Цифры к графику: `data/tables/place_nizhyn_origin_yearly.csv` и `_monthly.csv`.

Такой же график можно сделать для любого населённого пункта (название по-украински, как на сайте):

```bash
pip install matplotlib
python3 scripts/charts.py --skip-weekly --place Бахмут --oblast "Донецька область" --role event   # где погибли
python3 scripts/charts.py --skip-weekly --place Кривий\ Ріг --oblast "Дніпропетровська область"  # откуда родом
```

## Таблицы

Во всех таблицах есть колонки `dead` (погибшие), `missing` (пропавшие без вести),
`prisoner` (пленные) и `total` (всего).

**Динамика по времени** (по дате гибели, исчезновения или пленения):
- `national_daily`: по дням (только записи с точной датой).
- `national_weekly`: по неделям, неделя начинается с понедельника (`week_start`).
- `national_monthly`: по месяцам; отдельная строка для записей без даты.
- `national_yearly`: по годам, с 2014-го.
- `date_precision`: с какой точностью известна дата (день, месяц, год, неизвестна).

**Откуда были люди** (место происхождения):
- `regions_origin`: по областям, включая г. Киев. Есть население на 2022 год и
  потери на 10 тыс. жителей (`*_per_10k`), а также колонки `*_since_2022`
  (с начала полномасштабного вторжения).
- `regions_origin_monthly`: область × месяц.
- `districts_origin`, `communities_origin`, `settlements_origin`: районы, громады,
  населённые пункты. С координатами `lat`/`lon` для карт, населением и кодом КАТОТТГ.

**Где погибли или пропали** (место события):
- `regions_event`: по областям, включая Курскую, Белгородскую и Брянскую области РФ (`country = RU`).
- `regions_event_monthly`: область × месяц. Хорошо показывает, как смещался фронт.
- `districts_event`, `communities_event`, `settlements_event`: «горячие точки»
  (Бахмут, Мариуполь, Покровск, Работино, Авдеевка…) с координатами.

**Воинские части:**
- `units`: потери по бригадам и батальонам (название на укр./англ., номер в/ч).
- `units_monthly`: часть × месяц.
- `units_by_region_of_loss`: часть × область гибели.

**Со страницы статистики сайта:**
- `site_weekly_last52`: последние 52 недели (неделя с четверга по среду, как на сайте).
- `site_age_distribution`: распределение по возрасту.
- `site_status_breakdown`: доли по статусам.
- `rank_by_status`: офицеры, сержанты, рядовые и «неизвестно» × статус (из фильтров базы).

## Важные оговорки для видео

1. **Это только задокументированные, поимённые потери** из открытых источников
   (некрологи, сообщения громад, соцсети). Реальные потери выше, и неизвестно,
   насколько именно.
2. **Последние недели и месяцы всегда занижены.** Информация о гибели появляется
   с задержкой от недель до месяцев. Последняя неделя на сайте показывает 0.
   Падение в конце графика отражает именно эту задержку, а не снижение потерь.
3. **«Пропавшие без вести» — нестабильная категория.** Со временем многие из них
   подтверждаются как погибшие или оказываются в плену. Поэтому в 2025–2026 годах
   пропавших больше, чем погибших: свежие случаи ещё не подтверждены.
4. **Звание неизвестно у 123 тыс. записей**, из них 101 тыс. — пропавшие без вести.
   Доли офицеров и рядовых корректно считать только среди погибших.
5. **Потери на душу населения по Донецкой и Луганской областям** занижены: население
   на 2022 год не учитывает оккупацию и переселение. Население Киевской области
   не включает г. Киев, он идёт отдельной строкой.
6. Данные сайта для карты сгенерированы **25.10.2026**. Счётчик базы, страница
   статистики и звания получены **24.11.2026**.
7. Человек считается один раз на каждом уровне (область, район, громада, населённый пункт).
   Суммировать разные уровни между собой нельзя.
